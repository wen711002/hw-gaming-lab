📋

Part 1 — 如何送出測試需求（Form）

從左側導覽列點選「Form」進入需求申請表單
1

選擇「新建測試表單」或「複測」

第一次提出測試需求選「新建測試表單」，需從頭填寫完整專案與機台資訊；若是同一個專案已經測過、要追加測項或針對某些 SKU 重新驗證，請選「複測」。

📋 新建測試表單
全新專案需求，從頭填寫所有測試資訊與機台規格
🔄 複測
沿用既有專案資料，修改或新增測試項目與複測原因
2

（僅複測）輸入專案代碼，帶出既有資料

選擇「複測」後，直接輸入 Project Code 並按「LOAD」，系統會自動帶出該專案最新一筆既有資料（需求人、專案資訊、SKU 等），不用重新輸入。找不到代碼時也可改用下方「依專案篩選」逐層選擇。

3

選擇產品系列（Gaming／Consumer）

依專案所屬系列選擇 Gaming（Strix／TUF／ROG）或 Consumer（ZenBook／VivoBook），系統會依此篩選下一步「專案平台」的下拉選項。

4

填寫基本資料（Step 1／3：基本資料）

依序填入需求部門、需求人姓名與 Email（審核結果與所有通知都會寄到此信箱，請務必填對）、專案系列 / 平台、Project Code、Phase，接着在「此 Phase 測試機台 SKU」表格中新增每一台受測機的規格。

5

新增 Report（Step 2／3：Report 底稿上傳）

依「提交急迫度／重要程度」由上而下新增 Report（最多 5 份）。每一份 Report 都要各自上傳底板檔案、填寫測試開始日與提交日期、勾選這份 Report 對應要測的 SKU 機台，並可在 NOTE 補充「哪些測項可略過不測」等說明。需要更多份時按「＋ ADD REPORT」即可新增。

6

確認資訊並送出（Step 3／3：確認送出）

系統會整理出完整的表單摘要（需求人、專案資訊、SKU、每份 Report 明細），請仔細核對後按「SUBMIT REQUEST」送出。送出後系統會自動發信通知實驗室管理人員，並顯示您的 Report ID 供後續追蹤。

Part 2 — 如何查詢 / 下載測試結果（Result）

從左側導覽列點選「Result」查詢已提交專案的測試進度與結果檔案
1

選擇「整份 Result 下載」

進入 Result 頁面後，點選「整份 Result 下載」卡片，即可透過專案代碼查詢該專案所有測試結果通知紀錄，並直接前往 SharePoint 對應資料夾下載完整結果。

📥 整份 Result 下載
輸入專案代碼，查出該專案所有測試結果通知紀錄
2

輸入專案代碼查詢

在「專案代碼（PROJECT CODE）」欄位輸入您申請時使用的 Project Code（例：G814JV），按「查詢」。

專案代碼（PROJECT CODE）
例：G814JV
🔍 查詢
3

下載本次測試結果檔案，或前往完整資料夾

查詢結果會列出「完整結果資料夾」連結（可直接前往 SharePoint 瀏覽全部檔案），以及「本次測試結果檔案」清單 — 這是即時列出資料夾內目前所有結果檔案，只要檔案還在，不論複測幾次都會持續顯示、可個別下載，不會因為複測次數增加而遺漏。

⬇ 前往 SharePoint 下載整份 Result
📄 BatteryLife_Summary_UX3480AA.xlsx
最後修改：2026-07-23
⬇ 下載
4

檢視完成通知歷史紀錄

頁面下方會列出實驗室每一次發出的「部份完成」／「全部完成」通知，包含時間、負責人與備註說明（例如哪些 SKU 已完成、哪些需要重新複驗）。每一次通知都會被永久保留、依時間新到舊排列，不會被新的通知覆蓋掉。

❓ 還有問題？

若操作上遇到問題，或需要協助查詢排程進度，請直接聯繫實驗室負責窗口，或參考首頁「專案系列負責人」對照表找到對應系列的負責人。
